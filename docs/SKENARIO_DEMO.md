# Skenario Video Demo (± 3–5 menit)

1. **Pembuka (15 dtk):** sebutkan nama, NIM, judul aplikasi.
2. **Tampilan awal (20 dtk):** tunjukkan dashboard, daftar obat, dan status Aman/Menipis/Habis.
3. **Struktur kode (60 dtk):** buka VS Code, tunjukkan folder `components/`, jelaskan peran tiap komponen & alur props dari `App.jsx`.
4. **State (45 dtk):** tambah obat → tunjukkan dashboard berubah. Coba input kosong & nama ganda untuk menunjukkan validasi.
5. **Props (30 dtk):** klik + / − pada kartu obat (callback dari App → MedicineCard).
6. **Hooks (60 dtk):** tunjukkan kode `useEffect` di `App.jsx` (localStorage + judul tab) dan `Header.jsx` (timer + cleanup). Refresh halaman untuk membuktikan data tersimpan.
7. **Pencarian & hapus (20 dtk).**
8. **Penutup (10 dtk).**

Tips: rekam layar + suara, resolusi min. 720p, upload ke Google Drive/YouTube (unlisted) dan pastikan link bisa dibuka dosen.
